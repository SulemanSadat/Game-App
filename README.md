# 🎮 Game App

A modern **React game browsing web app** built with **Vite**.  
Users can explore games, search titles, filter by platform, sort results, and switch between dark and light themes.

This project was originally built with Create React App and later migrated to **Vite** for faster performance and easier deployment.

---

## ✨ Features

- Browse and view available games
- Search games by title
- Filter games by platform
- Sort games by title or version
- Responsive layout for mobile and desktop
- Dark mode enabled by default
- Light mode toggle
- Clean and modern UI

---

## ⚙️ Tech Stack

- React
- Vite
- CSS
- React Toastify
- Lodash
- PropTypes
